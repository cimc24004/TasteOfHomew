# いえのあじ | A Taste of Home

日本の田舎町を舞台にした、短編の一人称3D探索ホラーゲーム、いえのあじのSteam版のソースコードです。母との約束を破って友達の家へ遊びに行ったことをきっかけに、主人公の日常が少しずつ変わっていきます。エンディングは全3種類です。

[Steam版](https://store.steampowered.com/app/4161930/A_taste_of_home/?l=japanese) ｜ [Nintendo Switch版（レジスタ）](https://regista.co.jp/products/atasteofhome/)

## 担当範囲

個人制作で、企画、Unityでのゲーム実装、3Dモデル制作、レベルデザイン、Steamでの販売まで担当しました。Nintendo Switchへの移植時には、実機でUnityのMemory Profilerを使ってメモリ使用状況を確認し、描画設定やオブジェクトの表示範囲を見直しました。　生成AI Geminiを使用して開発しました。 

## 使用技術

Unity 6.2（6000.2.0f1） / C# / URP / Input System / Cinemachine / Timeline
